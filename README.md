# CN Lab

NS2 network simulation programs from my computer networks lab.

## What's inside

- `CLIENT SERVER` - client-server communication
- `DISTANCE VECTOR` - distance vector routing
- `FTP` - file transfer over the simulated network
- `Multicasting` - multicast routing
- `TCP` - TCP behavior
- `aodv.tcl`, `dsdv.tcl`, `dsr.tcl` - ad hoc routing protocols (AODV, DSDV, DSR)
- `error.tcl` - error model

## Running

These are OTcl scripts for NS2. Run one with:

```bash
ns aodv.tcl
```
